# WellMap

An interactive app to map, visualize and save microplate layouts.

## Key Features

- Switch between **96-well** and **384-well** plate formats.
- Support single, multiple, area, row and column selection of wells.
- Support combo treatments and drug titration.

- Save metadata in JSON; File can be reloaded to the app.
- Snapshot plate layout with custom metadata selection.
- Autogenerate accompanying metadata table.
